    2. Download Amiri Quran woff2 font file. Go to https://fonts.google.com/specimen/Amiri+Quran and use the Google Fonts API to get the woff2 file. The direct download URL for the woff2 can be obtained by:
       ```bash
       curl -s "https://fonts.googleapis.com/css2?family=Amiri+Quran&display=swap" -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36" | grep -oP 'url\(\K[^)]+\.woff2'
       ```
       Then download that URL and save as `public/fonts/AmiriQuran-Regular.woff2`.

       Alternative: Download the full family zip from https://fonts.google.com/download?family=Amiri+Quran and extract the woff2 file.

       The file MUST be a binary .woff2 file, not a CSS file or HTML page. Verify the file is > 100KB (Amiri Quran is a large Arabic font).

    3. Create src/lib/fonts/fontLoader.ts with the exact implementation from RESEARCH.md Pattern 2:
       ```typescript
       let fontsEmbedded = false;

       export async function ensureFontsEmbedded(): Promise<void> {
         if (fontsEmbedded) return;

         const response = await fetch('/fonts/AmiriQuran-Regular.woff2');
         if (!response.ok) {
           throw new Error(`Font fetch failed: ${response.status}`);
         }
         const buffer = await response.arrayBuffer();
         const base64 = btoa(
           new Uint8Array(buffer).reduce(
             (data, byte) => data + String.fromCharCode(byte),
             ''
           )
         );
         const dataUri = `data:font/woff2;base64,${base64}`;

         const styleEl = document.createElement('style');
         styleEl.textContent = `
           @font-face {
             font-family: 'Amiri Quran';
             src: url('${dataUri}') format('woff2');
             font-weight: normal;
             font-style: normal;
           }
         `;
         document.head.appendChild(styleEl);

         await document.fonts.load("1em 'Amiri Quran'");
         fontsEmbedded = true;
       }
       ```

       CRITICAL: Use `document.fonts.load()` — NOT `document.fonts.ready`. The `ready` promise is insufficient for dynamically injected @font-face rules (RESEARCH.md Pitfall 2).

       CRITICAL: The font MUST be fetched from same-origin `/fonts/` path — NOT from Google Fonts CDN URL. Cross-origin font fetch causes canvas CORS taint resulting in blank exports (RESEARCH.md Pitfall 1).
  </action>

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-01 | Tampering | public/fonts/AmiriQuran-Regular.woff2 | accept | Font file is bundled at build time, served from same origin. Not user-uploadable. Tampering requires build pipeline compromise — accepted as standard static asset risk |
| T-01-02 | Tampering | Zustand state rendered as HTML | mitigate | All store values rendered via JSX (React auto-escapes). Grep verify: no occurrence of dangerouslySetInnerHTML in src/ |
| T-01-03 | Tampering | shadcn CLI-generated component code | mitigate | Review generated files (button.tsx, select.tsx, slider.tsx, badge.tsx) after shadcn add — verify no dangerouslySetInnerHTML, no fetch/eval calls, no unexpected network requests |
</threat_model>
